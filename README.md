Penjelasan


program dimulai dengan dictionary produk yang berisi nama, harga, dan stock, dan setiap data punya kuci (key) dan isi (value).
- masuk ke perulangan (while true)
  program menampilkan menu (angka !-5) dan menunggu pengguna mengetik pilihan.
- pengguna mengetik angka pilihannya.
    - pilih 1 → program memanggil tampilkan_data(), yang mencetak semua isi dictionary produk ke layar.
    - pilih  2 → program meminta pengguna mengetik nama kategori, lalu menyimpannya sebagai key baru "kategori" di dalam dictionary. Setelah itu, data ditampilkan lagi supaya terlihat hasilnya.
    - pilih 3 → program meminta pengguna mengetik harga baru, lalu nilai pada key "harga" di dictionary diganti dengan angka itu. Data ditampilkan lagi setelahnya.
    - pilih 4 → program mengecek apakah key "kategori" ada di dictionary. Kalau ada, key itu dihapus. Data ditampilkan lagi setelahnya.
    - pilih 5 → program mencetak pesan penutup, lalu break dijalankan, yang menghentikan while True. Program selesai.
    - pilih selain 1–5 → program menampilkan pesan "pilihan tidak valid", lalu kembali ke atas (menu ditampilkan lagi).
 - kembali ke  langkah 2
   selama penggunna belum memilih angka 5, program terus kembali ke awal WHILE TRUE -menampilkan menu lagi, menunggu input lagi kembali ke atas(menu ditampilkan lagi).
 - program berhenti
   hanya berhenti saat BREAK dijalankan, yaitu ketika pengguna memilih angka 5.
